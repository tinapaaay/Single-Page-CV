# Single-Page CV

A semantic HTML CV website that presents my professional profile, skills, education, and contact information in one page.

This project was built as part of the [roadmap.sh Single-Page CV project](https://roadmap.sh/projects/single-page-cv).

## Features

* Semantic HTML structure
* SEO meta tags
* Open Graph tags for social-media sharing
* Favicon support
* Responsive viewport configuration
* Contact links for phone and email

## Built With

* HTML5
* CSS3

## Run locally

From the repository root, run `python3 -m http.server 5500`, then open [localhost:5500](http://localhost:5500). Python 3 is only a development-server option; VS Code Live Server also works. Stop the server with Ctrl+C. No package installation or build is required to serve this checkout.
